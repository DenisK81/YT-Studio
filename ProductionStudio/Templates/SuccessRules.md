# Success Rules

Living file. Append after every completed project's retro (see
`Documentation/SELF_IMPROVEMENT_PROCESS.md`). Story Agent and SEO Agent read this file on every
run. Never delete history — mark superseded entries instead, so patterns over time stay
visible.

## Format per entry
```
### {case_name} — published {date}
- Topic/angle: {what it was}
- Hook that worked: {first-30-seconds approach}
- Title used (of 3 generated): {which one, why}
- Thumbnail concept: {which, any notes}
- Retention notes: {where viewers dropped off, if known}
- Recurring issues to avoid: {anything QC caught that keeps happening}
```

## Cross-case patterns (derived from real YouTube Analytics, 2026-09-15 audit — not per-video
retros, since those below were never actually filled in despite 100 published videos; this
section exists so the real data isn't lost while that process gap gets fixed separately)

- **Title pattern of actual top-25-by-views videos (all-time, whole channel):** short (under 8
  words), punchy, and either a **direct first-person quote** ("I Murdered Him Because I Wanted
  Her", "The Text That Got Her Killed") or a **verdict/reveal statement** ("8 Years Later, The
  Verdict Finally Came", "24 Years In Prison For A Jealousy That Wasn't Real"). No question-mark
  titles and no generic "The Shocking Murder Of X" phrasing appear anywhere in the top 25.
  SEO Agent should weight these two patterns over generic case-description titles going forward.
- **Format performance split:** across 2026-06-01 to 2026-09-15, Shorts carried 87.3% of all
  channel views (`insightTrafficSourceType=SHORTS`); only 116 views channel-wide ever came from
  a Short driving a click to a related main video. Main videos are not being discovered by the
  Shorts-to-main funnel the 4-Shorts-per-case cadence implicitly assumes — see
  `Documentation/TREND_LOG.md`'s 2026-09-15 entry for the full breakdown and the real-photo
  bookending / REAL-badge / Track-3-mandatory countermeasures adopted the same day.
- **Process gap found:** the per-video retro entries below were never actually written despite
  100 published videos — `Documentation/SELF_IMPROVEMENT_PROCESS.md`'s retro step exists but
  hasn't been followed. Flagged, not yet fixed — worth resuming per-case retros once the current
  strategy-adjustment round of cases has enough real data to compare against these new rules.
